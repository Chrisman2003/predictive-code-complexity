# Predictive Code Complexity

Expandable project skeleton for the interdisciplinary project on transformer-based estimation of code complexity from problem descriptions.

## Repository structure

- `data/` – datasets and raw assets
- `src/predictive_code_complexity/` – package source code
  - `data/` – dataset loading and preprocessing
  - `models/` – model definitions and training logic
  - `evaluation/` – validation and analysis scripts
- `tests/` – automated tests
- `notebooks/` – exploratory notebooks
- `pyproject.toml` – Python project configuration
